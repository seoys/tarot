## 3. 변경 없는 항목

- 컴포넌트 구조 및 props 인터페이스
- 애니메이션 로직 (`useTarotShuffle`)
- API 연동 로직 (`tarot-card-analysis.ts`)
- 타로 카드 데이터 (`tarot-data.ts`, `mbti-data.ts`)
- 폰트 (Playfair Display + Plus Jakarta Sans 유지)
- 레이아웃 구조 (3-step funnel 구조 유지)

## 4. 구현 순서 (권장)

1. `globals.css` — 컬러 토큰 교체 (전체에 즉시 반영되므로 첫 번째로)
2. `page.tsx` — 배경 글로우, 부제목, getHelperText, Toast 문구
3. `BirthdateStep.tsx` — 제목, 독백 인용구, 레이블, placeholder, 버튼
4. `MbtiQuizStep.tsx` — 진행 텍스트, 질문 접두어
5. `QuestionInput.tsx` — 레이블, placeholder
6. `CardSelectionDialog.tsx` — 카운터, 힌트, 버튼 텍스트, 다이얼로그 내용
7. `PreviewCardDialog.tsx` — 설명, 닫기 버튼
8. `CardInterpretations.tsx` — 모달 제목, 아이콘, 재시작 버튼
9. `SelectedCardsSlots.tsx` — 안내 문구
