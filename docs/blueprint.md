# **App Name**: Tarot Reader

## Core Features:

- Card Display: Display a layout of tarot cards faced down.
- Card Shuffling: Add a button to shuffle the tarot cards.
- Card Selection: Allow the user to select up to 5 cards.
- Card Selection Summary: Generate a layer popup showing which cards were selected and a brief summary of each card.
- Card Image Links: Apply links to free tarot card images.
- Card Analysis API: Call an API for card analysis and display the results in a popup when the user confirms their selection.

## Style Guidelines:

- Use a dark, mysterious background color (e.g., dark purple or deep blue).
- Accent color: Gold (#FFD700) for highlights and interactive elements.
- Use elegant, slightly mystical typography for card descriptions and interpretations.
- Incorporate subtle celestial or esoteric icons.
- Card layout with a touch of asymmetry to mimic a real card spread.
- Subtle card flipping animation on selection.
